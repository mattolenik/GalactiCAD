# Upper-handoff C: ownership exclusion after correct ancestor evaluation

Frozen source `/tmp/sfcc-upper-c`, parent `/tmp/sfcc-stage4-c`, flat patch baseline
`/tmp/sfcc-stage3-base`. All additions are test-only. The selected lower repair,
ordinary feature construction, ownership band and complete source-admission gate
are unchanged. Author performed static inspection and rustfmt parsing only; root

## Independent question

B addresses an actual intermediate-chamfer evaluator defect. C asks whether that
correction alone supplies the outgoing representation's domain at the handoff.
`FieldRef::surface_live` rejects a lifted field whose nonempty target path has
`abs(actual_target_value) <= native_band`, before accepting its selected branch.
That is an ownership exclusion, not a theorem that no source crease exists there.

In the active outer-round formula, an ideal parameterization is
`q=r*(cos(phi)-1)` and `S=r*(sin(phi)-1)`. It approaches the native q=0 branch
continuously. Any positive band excludes a nonzero interval of sufficiently small
positive phi, and band zero still excludes the exact q=0 closure point. This
conditional algebra does not by itself establish the actual primitive and ancestor
premises; A's independent source theorem addresses those. C does not manufacture
an endpoint or treat sampled proposals as a continuous proof.

## Implemented discriminator

A scoped test-only toggle recomposes **binary intermediate chamfers** with the
existing `sample_blend` on the overridden child and actual sibling. Explicit
path-empty `FieldBranch::Chamfer` support branches remain unchanged. This is the
same binary semantic correction B proposes, used only during finite field queries;
C does not compile a modified feature graph or alter runtime evaluation.

The test builds the exact original pipeline context, reuses the source-bound
physical/alias selector, and finds the actual generated hard-Max Child(0/1)
FieldRefs under the outer owner by their source paths and descriptors. No dense
stratum IDs supply identity. It derives a numerical activation-height proposal
from the actual sphere/cylinder/round coefficients. For six nearby heights it
forms a native-side/cylinder equal-value proposal and solves radius by bounded
bisection using the **existing root evaluator**. There is no new scene evaluator.
The existing full source and both hard operands then check the proposals.

For each point, the receipt records original/corrected lifted field values and
gradients, current domain decisions, real ownership band, zero-band and completely
disabled-band counterfactual decisions, and actual source identity. The original
native-zero region is also observed: unconditional deletion of the ownership rule
can admit lifted domains over a region already represented by native curves.
That is overlapping domain permission, not an assertion that a compiled duplicate
edge was emitted. Setting the cloned test descriptor's band to -1 implements
that deletion counterfactual only; no negative band is admitted to runtime.

The acceptance assertions require both sides of the sampled band boundary, low
actual root residual, equal actual hard operands, nonvanishing tested normal gap,
and corrected geometric-domain validity when exclusion is disabled. Source
fingerprint stays unchanged and the scoped toggle resets after normal return and
an injected unwind. The JSON is written before these gates, bounded by512KiB.

## What this does not prove or change

- No continuous outgoing existence/uniqueness, complete interval-domain or scalar
  identity theorem is inferred from these points.
- No exported geometric hole or actual tolerance failure is inferred merely from
  exact-source ownership exclusion; approximate native geometry may cover part of
  the same spatial region within its numerical bands.
- No global zero-band/disabled-band policy is proposed. Those changes could overlap
  ownership or conflate exact source closure with discovery activity.
- No outgoing chart, shared junction, parameter transport or endpoint wiring is
  installed. Complete admission must still pass before component reconstruction.
- The activation coordinate is a numerical proposal, not a certified exact event;
  its rounded target may differ slightly from zero. The exact-zero ownership
  statement follows directly from the predicate and is labelled separately.

The useful next contract is to distinguish discovery ownership from source-valid
arc closure and connection authority. A source theorem may justify a specific
one-sided handoff; a nearby point, a residual band or unconditional ownership
removal cannot substitute for it.
