  whole-eligible-export reconstruction. Healthy paths pay only an O(leaves) flag scan. The standalone
  constructor also handles complete nondegenerate cell targets; nondegenerate legacy meshing failures
  are not yet production fallback triggers.
- Original signed Min/Max tree is evaluated symbolically on ALL plane/open product strata using exact
  ranks, never rounded midpoint probes. Original occurrences and ancestor paths remain distinct.
- Zero-only faces and unrepresented zero edges/points are explicitly rejected. Full edge/vertex-link
  checks reject edge/point contacts. Ordinary coincident planes and duplicates preserve all ownership.
- Every exposed primitive facet is subdivided by all actual leaf-boundary coordinates, then each
  microrectangle must have exactly one actual owning leaf. Missing/overlapping ownership fails.
  Common rank-coordinate identities enforce coarse/fine and cross-worker agreement without welding.
- Exact derived crease graph, true original stratum ownership and complete intervals replace reliance
  on potentially incomplete old traced features. Derived feature sets use the existing unique run-ID
  allocator. Elementary segment endpoints are graph vertices; this may restrict quality remeshing
  more than a future maximal-curve representation.
- Existing assembly/quality passes remain active. Complete per-cell snapshots use existing checked
  planar flip transport. Unproved edits withdraw proofs and do not spuriously trigger serial recovery.
  No debris exemption remains: existing closed-component preservation already suffices.
- Initial f32 embedding is proved only when every exposed carrier plane survives f32 exactly and
  every canonical cut coordinate retains strict finite order. Otherwise the fallback is unresolved.
- Worker wrapper carries full prepared manifest and group ownership plus actual partial geometry.
  Receiver reconstructs the exact expected per-cell payload, verifies the received bytes, and merges
  transmitted triangles. It does not substitute a serial reconstruction for worker output.
- Fixed occurrence/depth/stratum/coordinate/rectangle/ownership work limits precede large arrangement
  allocations. Work/memory remain intentionally conservative; workers and receiver repeat target work.
