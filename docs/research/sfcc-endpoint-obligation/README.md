## What the exposure discriminator shows

At the stored endpoint, the existing exposure predicate returns alive. At five
predeclared positive advances from 0.0001 to 0.004 mm, projected supporting-pair
samples remain in both carrier domains with small full-field residuals, while
the default flank probes return dead. Reducing only the diagnostic probe distance
by 32 makes those same samples return alive. The first continued probe lies within
the continuously checked height neighborhood above.

For example, at 0.0001 mm advance the full-field residual is approximately
`4.16e-10`, yet the default cylinder-side flank fails and the smaller probe passes.
The original schedule stops at scale 1/16 of the 0.1 mm probe, before accounting
for direction magnitude. Failure of that finite search does not prove that no
arbitrarily small surviving flank exists.

This is a demonstrated numerical exposure-classification counterexample and a
strong lead for the upstream loss. It is **not yet the captured lineage of the
actual raw trace that became corner 27**. Merely reducing the global probe factor
would move the failure threshold without establishing correctness. The
[discriminator receipt](C/endpoint-C.json) retains all predeclared results.

The same test exposes a separate branch-representation gap: propagating a deeper
hard-intersection branch through an intermediate chamfer selects its diagonal
formula while that chamfer is actually in a child-dominant region. Both tested
overrides return about `-0.80338835` at a point where the complete field is near
zero. This may matter for later displaced continuation, but does not establish
the cause of the earlier stored endpoint; native ownership and displaced branch
ownership are distinct. See [C's full interpretation](C-packet/handoff.md).

Degree-one feature vertices are not inherently invalid: A/B/C's review retains
the counterexample surface `z = max(x,0)^2 |y|`, whose crease ends with a vanishing
normal jump while the surface remains a disk. The knob's local source checks rule
out that explanation here. Restoring a duplicate label on the same canonical
edge also cannot provide a second distinct geometric neighbor.

## Next discriminator and remaining limits

Trace the actual source compilation from raw carrier trace through trim runs,
endpoint refinement, corner merge and final curve remaking. Record the exact
source-pair lineage and the existing classifier operands at the first loss,
without adding queries or changing the resulting feature fingerprint. This is a
bounded feature-only experiment; the successful local replay eliminates any need
to rebuild the octree just to revisit the degree guard.

The source-correctness regression for a subsequent repair must require continuation
through the checked neighborhood, with source identities and ordered intervals
preserved. Passing the old degree guard alone is insufficient. The actual outer
rounding transition also lies later inside this failed cell, so simply extending
the native endpoint a little cannot establish a complete component replacement.
