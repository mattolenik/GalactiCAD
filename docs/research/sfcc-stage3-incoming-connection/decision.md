## Why A's connection is justified

A does not promote the old Newton parameter map into a continuous or monotone
map merely because finite point queries agree. It replaces the uncertified raw
prefix with a source-derived parameterization. Its admissible family is narrow:
identity/coaxial frames, the reviewed ordered ancestor structure, a selected
horizontal twisted-profile side, a convex groove profile and a raw open START
whose original classification interval lies in the first knot span. Groove axial
translation is additionally restricted to zero. Unsupported inputs remain unresolved.

For actual cylinder radius R and the represented incoming radius r_i<R, the ideal
chart uses rho(s)=R+(r_i-R)s, s in [0,1]. The actual groove offset line determines
height. The profile side fixes one intrinsic coordinate, while the other is the
fixed-sign square root of rho squared minus that fixed coordinate squared. Actual
source twist gives the world coordinates. The preserved raw ID and parameter
range record an explicit affine reparameterization; they do not assert every old
Newton query equals the replacement query.

The source checker binds immutable native, parent-field, cylinder and compound
occurrences. It establishes the genuine source junction independently of the
candidate corner, and checks the entire incoming interval: selected groove-edge
interior and closest-edge separation, selected convex profile side, finite caps,
nonzero intrinsic branch, inactive inner round-union competitor, cap subtraction
and outer round. Since r_i<R, the cylinder is strictly inactive on every open
s>0 and equal at the junction by construction. The regular source intersection
therefore provides the connecting physical arc, not a nearest-point guess.

The generated compound's represented offset/weight is checked separately from
the ideal source chamfer radius. Their difference is bounded rather than called
zero. Directed angular/cap bounds and an independent source-image association
control the numerical endpoint and incoming join. Every actual chart query still
checks both original normalized carrier residuals at refine.curve_eps and the
existing displacement-box postcondition.

The ideal chart has continuous parameter order. Strict ordering of every rounded
output is not claimed: in particular, the exact stored corner override can differ
slightly from the ideal endpoint. The 33 executed events are ordered and each
query is source-associated, but those tests do not prove floating evaluator
continuity or totality. Stage 4 must validate the consumed f64/f32 geometry.

then discarded by legacy sampled deduplication in favor of an earlier ordinary

## B: useful theorem, rejected failure transaction

B proves a continuous source connector and bounds its complete short chord using
an outward second-derivative bound. For u=sqrt(rho^2-v^2) and theta'=k, it uses
|u''|+2|k*u'|+k^2*rho, then adds endpoint association and interpolation-rounding
bounds. It also bounds every original seed on the admitted raw span. This is a
uniform theorem, not a claim inferred from finite samples.

On the actual witness, its chord error bound is 1.2379219471e-8 mm and its original
seed bound is 1.2379242671e-8 mm, below unchanged curve_eps=4.7458192127e-8 mm.
The generated-level discrepancy bound is 2.2204460493e-16 mm. Its corrected
queries return exact endpoint values and use monotone rounded affine interpolation
with clamping in between; successful outputs have non-strict represented height
order. They preserve source/carrier checks, explicit refusal, chord tangents and
query-mode identity/storage. B-final's conservative overlap refusal also restores
the symmetric family's exact parent behavior and retains the one admitted mode.

However, making remake_curve fallible introduced a plain `continue` on None in
trim emission. That can delete the entire run after a certificate-install failure,
a join excluded by a later split or another unsupported remake. It neither restores
the previous unresolved interval nor reports a new refusal there. Passing the
actual happy-path gate and rejecting a direct remake call do not test this caller
behavior. A source-bound connection theorem does not excuse lost geometry on a
failed transaction. B-final is not selected until that failure preservation is
implemented and tested. No weakened gate or retained duplicate edge is recommended.
