## Interval and numerical-query authority

A's certificate binds actual source occurrences, shared compiled carrier, original
curve IDs/ranges and a canonical radial source interval. For the first cell it
supports these prefixes:

The ideal radial interval is enclosed by [10.79,10.8]. Its source curve uses the
finite native side, the actual groove-offset equation and the original twist.
Height is affine in radius, with derivative bounded below by about 2/3. Physical
and generated-carrier images are derived separately because the represented
compiled offset divided by its weight need not equal the physical chamfer radius.

An initial candidate tried to prove the finite-profile restriction over the entire
old projection tube. That premise failed: the permitted tube is substantially wider
than the actual source curve. The failure is preserved; it does not prove that
the observed curve queries were wrong.

The selected contract instead proves the alias equation over the **whole canonical
physical/generated image enlarged by the unchanged association allowance**. Every
accepted actual query must lie in this qualified region **and** its independently
retained original projection tube, and must associate directly to both source images.
The finite native profile and inactive inner-round competitor are proved throughout
the qualified region; the selected untwisted branch sign excludes the opposite branch.

This is conditional authority for accepted queries. It does not assert that every
possible old Newton query is valid, continuous or total, or that every raw chart
parameter maps monotonically without checking. The finite consumed event sequences
are explicitly checked for order. The canonical source theorem does not itself
certify all two-dimensional mesh patches.

The actual canonical image is used for the competitor bound; an earlier coaxial
surrogate was corrected before selection. The final checks retain the original
source, range, residual, container and numerical association restrictions.

### Accounting remains explicit

Pre-meshing queries charge the original private ledger before evaluation and require
the same immutable feature instance. Meshing queries require an active generated
scope and use the ordinary checked-query entry, so every attempt is covered by the
existing 2,048-slot reservation and query log. The two contexts reject misuse;
generated queries are not also charged as external work.

The inverse remains bounded by 64 requests/iterations and the original 16,384 total
policy. It uses checked height proposals, then bounded bisection; only the actual
three-dimensional match grants correspondence. Failed queries and abandoned work
remain accounted for. The final local replay retains the full generated reservation:
charge is 2,311 before post-validation and 2,495 afterward. These local charges are
not directly comparable to the complete constructor's work.

The first scope exceeds the unchanged 256-cell/1,536-face caps. It is an overbroad

not completed interval equivalence or transaction validation.

The final added cell `[8,55,114,172]` has an unmatched required frontier face
`[1,3662165,1]`, carrying only curve 66 at parameter 5.083647992574102. The native
representation ends inside that region. Its declaration cannot be assumed to be
a physical terminal or to match curve 66's complete continuation.

Direct existing-evaluator samples provide a counterexample to whole-curve equality:

The inner blend is active there: E and the composite field differ even though the
point remains near the full surface. Curve 66 subsequently continues with a positive
native field while its composite field remains near zero. A global alias merge is
therefore invalid. The location and required handling of the activation event are
not yet certified.

Separately, the current `lathe_lower` proof helper requires radius greater than every
profile-vertex radius. It can refuse a larger interval before the blend actually
activates. For example, the t=15 sample still has competitor 1.44854 > 1.4 despite
falling outside that helper's sufficient region. A failed certificate is not evidence
of physical activation; the direct t=16 discrepancy is the actual counterexample.
