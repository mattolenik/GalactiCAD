\paragraph{Decision.}
Implement a conservative, original-tree zero-owner enumeration, followed by
primitive cell, edge, and face visibility checks. An inconclusive supported
check requests subdivision; at the existing depth ceiling it remains an
unresolved cell. Apply the same guard before both feature-corner acceptance
paths and in the public smooth-refinement entry point. Retain the existing
split/degenerate reporting channel and ordinary feature/quality criteria.

This is a \emph{necessary discovery condition}, not a sufficient certificate
that every hard-CSG component, local patch, or output triangle is accounted
for. Call success \texttt{NoDiscoveryRejection}, never \texttt{Complete} or
\texttt{Covered}. The supplied hidden sphere is within the proved rejection
class. Section~\ref{sec:limits} gives a different hidden component that passes
the guard, so the boundary of the result is testable rather than implicit.

\section{Zero ownership and sound exclusion}

Let \(Q\subset\R^3\) be a closed cell. Initially let \(F\) be a finite,
nonempty min/max tree of continuous signed fields \(f_i\).
A leaf identity is an \emph{occurrence}, including its sign and ancestor path.
At a point \(p\), occurrence \(i\) is a zero owner if its own value and every
node on that path equal zero. Leaf/root equality alone is insufficient:
\(\max(\min(A,B),C)=0\) with \(A=0,B=-1,C=0\) does not expose \(A\).

Suppose every interval \(I_v(Q)=[L_v,U_v]\) encloses its node's values on \(Q\).
For hard nodes use
\[
 I_{\min_j v_j}=[\min_j L_{v_j},\min_j U_{v_j}],\qquad
 I_{\max_j v_j}=[\max_j L_{v_j},\max_j U_{v_j}].
\]
Correlation loss enlarges the possibilities; it does not invalidate these
enclosures. Define the candidate set
\[
 \mathcal C(Q)=\{i:0\in I_v(Q)\text{ for every node }v
                       \text{ on the path from }i\text{ to the root}\}.
\]

\begin{theorem}[Zero-owner cover]
Every root-zero point has at least one zero owner. Every occurrence owning
a root-zero point in \(Q\) belongs to \(\mathcal C(Q)\).
\end{theorem}
\begin{proof}
A finite min or max attains the value of some child. Starting with a root
value zero, repeatedly choose an attaining child; this gives a path of zeros
ending at a leaf. Conversely, every node on any zero-owning path has value
zero at that point, so its enclosing interval contains zero.
\end{proof}

At a min ancestor, a zero child survives only where every sibling is
nonnegative. A sibling bound \(U_s<0\) therefore excludes the route throughout
\(Q\). At a max ancestor the dual exclusion is \(L_s>0\). These strict tests,
or equivalently a zero-excluding interval at any ancestor, are valid for
negative leaves and arbitrary alternating hard nesting. Equality and ties
remain possible. A sampled non-winner is not an exclusion.

Compute the intervals once in postorder. Append candidate references while
walking children, and truncate the current subtree's appended entries when
its interval excludes zero. This is \(O(N)\) node/interval work with
\(O(P+h)\) temporary storage for peak pending candidates \(P\le N\) and
height \(h\). A subtree can append many candidates before its parent excludes
them; a vector retains that peak capacity even if the final candidate count
\(K\) is small. The traversal does not recursively recompute sibling trees
once per candidate.

\paragraph{Unsupported subtrees.}
A blend zero need not be a primitive zero. Stop at a blend or unsupported leaf
and retain it as an opaque entry with interval \([{-\infty},+\infty]\).
Do not stop at a hard node merely because one descendant is unsupported;
visit its other branches. An ancestor can remove this entry only by
its own valid exclusion. This extends the theorem to a hard tree whose atomic
fields include opaque subexpressions, without claiming primitive coverage
inside them. Keep the opaque/scope marker alongside the supported candidates;
never encode it as a proven-empty vector. Supported candidates elsewhere in
the same expression still receive the guard. The opaque entry alone does not
force the legacy blend/unsupported pipeline to maximum depth.

\section{The chosen guard and its exact guarantee}

For a retained sphere/cuboid occurrence, assume a finite nondegenerate convex
solid under a valid positive uniform similarity. Its sign may be either
orientation. For each corner, obtain a \emph{strict} sign; the existing leaf
box interval with zero half-extents can supply a conservative point-sign
query. An interval touching zero, an invalid interval, or uncertain arithmetic
does not supply a strict sign.

Apply these checks independently of all normal/curvature settings:
\begin{enumerate}[label=G\arabic*.]
\item If the eight primitive corner signs are not all reliable, or are all
the same, request subdivision. The candidate's cell interval already includes
zero; neither a center winner nor a root sign change discharges this check.
\item For each of the 12 edges whose endpoint signs agree, require the leaf
interval on that edge to exclude zero strictly. Otherwise request subdivision.
Represent an edge by a box with two zero half-extents.
\item For each of the six faces whose four corner signs agree, require the
leaf interval on that face to exclude zero strictly. Otherwise request
subdivision. Represent a face by a box with one zero half-extent.
\end{enumerate}

The pre-existing whole-field same-sign rule also remains a discovery rule:
in a fully supported hard tree, no reliable root corner sign change plus an
inconclusive root interval requests subdivision, including a feature-corner
cell. A feature tag may exempt sampled smoothness; it does not prove discovery.
Where unsupported opaque entries remain, preserve legacy behavior except for
rejections already justified by retained supported candidates.

\begin{theorem}[Necessary primitive visibility]
Under the enclosure and strict-sign premises, a supported cell passing G1--G3
has the following properties for every possible supported zero owner:
its primitive has mixed corner signs; each cell edge contains no primitive
zero when its endpoints have equal signs, and exactly one primitive zero
when they have opposite signs; every face with homogeneous primitive corner
signs contains no primitive zero.
\end{theorem}
\begin{proof}
G1 and the zero-owner cover prove the first assertion. Interval exclusion
proves the equal-sign edge and homogeneous-face assertions. Undo the leaf sign
on an opposite-sign edge. One endpoint is strictly inside a convex sphere or
box and the other strictly outside. The solid's intersection with the line is
an interval, whose interior endpoint-to-exterior endpoint portion has exactly
one boundary exit. These primitives have no zero plateau on such a segment.
\end{proof}

\begin{corollary}[Wholly hidden primitive]
An exposed nondegenerate sphere or box wholly contained in a cell cannot pass
G1, even when another branch creates the root's corner sign change. The same
holds for a contained cavity represented by a negative occurrence.
\end{corollary}
\begin{proof}
Every cell corner lies outside or on the primitive boundary, so its signs
are homogeneous or uncertain; reversing the occurrence's sign preserves this
property. An exposed zero retains its occurrence
by the cover theorem. G1 rejects the homogeneous signs.
\end{proof}

For the supplied regression, the sphere has center
\((0.04125955406450752,1.53,1.53)\), radius
\(0.01650382162580301\), and a positive gap to the box face \(x=0\).
At depth 8 the jittered cell has side \(0.796875\) and bounds approximately
\[
\begin{aligned}
 x&\in[-0.08251910812902,0.71435589187098],\\
 y&\in[1.447911753179639,2.244786753179639],\\
 z&\in[0.749845832607463,1.546720832607463].
\end{aligned}
\]
The entire sphere lies strictly inside it. Its own corner signs are positive.
Thus this cell requests a split at the ceiling and is unresolved, regardless
of whether its box portion yields a closed mesh. Sound ancestor/cell exclusion
cannot discard a cell containing these exposed zeros earlier.

\section{Adjudication and explicit limits}\label{sec:limits}

The three independent proposals agree on occurrence-level exclusion and the
existing unresolved channel. Their acceptance policies differ materially:
\begin{itemize}
\item A's own-corner guard suffices for the supplied contained primitive, but
misses invisible double edge roots and closed face contours. G2--G3 are
constant primitive queries and close these specific gaps, so they are included.
\item B's cell/edge/face checks are the selected necessary guard. Its proposed
rewrite to feed every carrier into smoothness is not required for this
discovery contract; sampled smoothness remains an approximation heuristic.
\item C's single-equivalent-primitive, single-disk condition is a useful
sufficient special case, but is not a mandatory acceptance gate here. At a true
seam, two inequivalent zero-owning primitives survive at every depth. Making
that condition mandatory would mark every such seam unresolved, even when its
feature representation is already adequate. That is a substantially different
acceptance policy from this targeted repair.
\end{itemize}

\paragraph{Edge adversary.}
A unit sphere in
\([0.919,0.999]\times[-0.04,0.04]^2\) has mixed corner signs and four
disconnected surface patches. On the high face,
\(y^2+z^2\ge 0.001999\), with
\(0.04^2<0.001999<2(0.04)^2\). Thus the patches cannot cross either
coordinate axis. Each high-face edge has two roots despite positive endpoint
values. Its sampled normal cone is about \(7.05^\circ\); G2 rejects it.

\paragraph{Face adversary.}
A radius-10 sphere in
\([8.99,9.99]\times[-0.5,0.5]^2\) passes own-corner and same-sign edge
checks. On the high face, every edge has squared radius at least
\(9.99^2+0.5^2=100.0501>100\), but the face contains a closed zero circle
of radius \(\sqrt{0.1999}<0.5\). G3 rejects this case. Edge checks alone
do not prove that every face contour reaches its boundary.

\paragraph{A hidden component that still passes the guard.}
In \(Q=[-1,1]^3\), intersect two spheres centered at
\((10,0,0)\) and \((-10,0,0)\), both of radius \(10.01\). Their lens is
contained in
\[
 |x|\le0.01,\qquad y^2+z^2\le 10.01^2-10^2=0.2001.
\]
It is wholly inside \(Q\). Each sphere nevertheless has four inside and four
outside cell corners, unique roots on its sign-changing edges, and strictly
zero-free homogeneous faces and edges. Union this lens with
\([-3,-0.5]\times[-3,3]^2\). The box supplies mixed root corner signs and
is disjoint from the lens. Every retained primitive passes G1--G3.
Complete seam-loop discovery may reject the cell later; G1--G3 alone cannot.
This exact counterexample rules out interpreting the chosen guard as universal
hidden-component detection, even within sphere/box hard CSG.

More generally, one carrier may be clipped into several exposed pieces.
A sampled owner, a primitive ID, or a sampled normal cone is not a component
identifier. Full local component acceptance still needs a proved regional
arrangement/topology certificate, or explicit unknown when that stronger
certificate is requested. Triangle embedding, geometric error, and f32
quantization remain separate obligations. The existing validation disclaimer
in \path{src/sfcc/validation.rs:1--3} must remain accurate.

\paragraph{Why C's sufficient special case is plausible but deferred.}
With complete candidates all having one identical signed primitive geometry,
a certified connected primitive surface \(S\) and a reliable root sign change
imply \(F^{-1}(0)\cap Q=S\). Indeed root zeros are a nonempty closed subset
of \(S\). If they had a relative boundary, take nonzero-root points on \(S\)
approaching it and fix an attaining leaf/path along a subsequence. That leaf
is not the common primitive, whose value on \(S\) is zero. At the limit its
whole path becomes zero, contradicting candidate completeness. Hence the
subset is also open and equals connected \(S\). A single-disk proof additionally
requires complete transverse edge/face intersections and one boundary cycle;
G1--G3 intentionally do not supply or claim that general topology test.

\section{Numeric and implementation obligations}

The proofs are exact-real statements conditional on valid enclosures and
reliable strict signs. The current \(32\epsilon\) leaf-box allowance has no
complete published derivation for arbitrary transforms, magnitudes, or
subnormal arithmetic. It is an engineering allowance, not a universal f64
proof. Existing root empty-culling has the same qualification. Reusing the
full original tree avoids an additional dependence on unrounded ball-pruning;
it does not repair all numeric assumptions of the exporter.

Within the new query, require finite ordered cell coordinates, positive cell
size, finite positive scale/radius/box extents, sign \(\pm1\), and finite
transform entries. A genuine similarity is a modeling premise. Reject an
obviously invalid rotation; a tolerance check for orthogonality is not an exact
proof that a rounded matrix is orthogonal. Nonfinite/inverted bounds, collapsed
geometry, zero-touching point intervals, and unresolved arithmetic request
refinement. Intentional opaque full-range intervals are a separate state from
arithmetic failure. Do not let f64 min/max silently hide a NaN. Regions passed
to interval queries must conservatively contain the actual cell/edge/face.

\begin{itemize}
\item Preserve original borrowed occurrences; do not deduplicate by
\texttt{node\_id}, \texttt{Leaf.index}, sampled owner, or a pruned child position.
Raw constructors use index zero and may have no strata. G1--G3 need neither.
\item Exact duplicate occurrences need no special geometric deduplication:
they make the same guard decisions. Opposite signs retain their distinct
ancestor semantics. Approximate equality must not erase a thin shell.
\item Whole-cell ancestor exclusion is the chosen burial mechanism. With a
resolvable strict burial margin it excludes inert primitives as cells refine.
When a tiny buried primitive and the outer wall share a finest cell, intervals
may remain inconclusive; a conservative unresolved report is permitted.
\item Support-AABB tightening is deferred. It is sound only with an enclosing
primitive support box and every ancestor test on that restricted domain.
The current transformed-corner AABB has no outward-rounding proof; recomputing
whole subtrees per candidate can also introduce \(O(NK)\) work. Neither is
needed to fix the stated regression.
\item Use one shared guard in direct smooth calls and before both corner
returns. Earlier feature/forced split decisions need no extra discovery query.
Pass the original root separately from the pruned numerical query if needed;
do not change all \texttt{SdfQuery} implementors merely to recover that root.
\item Do not add a user knob, increase depth, skip large leaf counts, or clear
degeneracy after successful meshing. No new worker flag or validation
\texttt{Complete} boolean is warranted.
\end{itemize}

\begin{enumerate}

\item Exercise center-winning hidden primitives, negative cavities, nested

\item Include the exact edge and face adversaries above, ordinary sphere and

\item Include the lens example as an explicit scope test: guard success does

\item Test both corner exemptions, direct smooth calls, disabled/loosened
quality knobs, and deliberately insufficient depth. Split requests must keep

\item Test serial, resumable, and 1/2/4/8-partition decisions, tagged-leaf

no-recovery fixture with zero failed cells to prove raw unresolved propagation;
separately test recovery and preserve existing public serial/worker parity.
\item Cross the actual 12-leaf pruning threshold. The discovery input must
still be the original tree. Compare actual zero-owner retention, not equality
of arbitrary conservative candidate supersets.
\item Translate and positively uniformly scale scene, cube, padding, and
geometric tolerances together; include rotated boxes and differing scale
factorizations. Tiny features below numeric resolution may become unresolved,
never be deliberately excluded by an absolute small-radius threshold.
\item Test explicit opaque scope and invalid arithmetic. Unsupported must not
be mistaken for proven empty, and a mixed expression's retained supported
hidden sphere must still reject. Invalid new-query inputs must fail closed.
\end{enumerate}

For each decided cell, the chosen implementation uses \(O(N)\) interval
enumeration plus at most \(26K\) primitive point/entity interval queries
(eight corners, 12 edges, six faces), short-circuiting on rejection. With
the already computed cell bound, that is at most 27 region queries per
retained primitive. It uses \(O(P+h)\) scratch, where \(P\le N\) is the peak
pending candidate count rather than the final \(K\), no per-cell scene clone,
and the unchanged finite depth ceiling. It promises no uniform bound on
false-positive refinement or ordinary-scene timing.

Measure release medians and structural counters against baseline on a box,
sphere, ordinary hard seam, the regression, duplicates, buried leaves, and an
existing many-leaf benchmark. Report decided/final/degenerate cells and query
work. A full-scene scan hidden inside every candidate query is a complexity
failure. Blanket maximum-depth refinement of a flat box is a failed control.
Tests and timings are evidence about the implementation, not a replacement
for the enclosure premises or a proof of the remaining component theorem.

\section{Milestone-2 implementation consensus}

The implementation uses the shared \texttt{discovery\_guard} in
\path{gcad-wasm/kernel/src/sfcc/refine_criteria.rs}. Its success result is
\texttt{NoDiscoveryRejection}, carrying a surviving opaque-scope flag.
\path{gcad-wasm/kernel/src/sdf.rs} enumerates original borrowed signed leaf
occurrences in one postorder append/truncate pass. Checked queries reuse the
existing primitive box enclosure; no primitive field formula is duplicated.
Malformed supported geometry and failed arithmetic are distinct from opaque
blend/unsupported subexpressions. The checks reject collapsed local or world
extents and grossly malformed proper-rotation matrices. Their \(10^{-6}\)
orthogonality/determinant tolerance is a sanity check, not an orthogonality
or floating-point enclosure proof.

Eight strict primitive corner signs are cached as a bit mask. Equal-sign edge
and homogeneous-face boxes use the actual probe endpoints, preserving zero
widths and rounding nonzero half-widths outward. A second linear structural
walk reconstructs root corner signs with bitwise OR at min and AND at max,
without any further primitive interval queries. An entirely omitted subtree
returns no mask. At its retaining parent its excluded field must have the
strict neutral sign: positive under min, negative under max; otherwise that
parent would also have been excluded. It is therefore skipped there rather
than assigned the identity of its own nested operator. Matching uses original
leaf addresses and traversal order, so duplicate indices do not merge
occurrences.

Both feature-aware entries run discovery on the original root before their
corner exemption, preserving tags when it requests a split. Direct
\texttt{needs\_split\_smooth} now requires the original \texttt{CsgNode};
all repository direct callers already provide it. The feature-aware entries
then invoke the remaining generic quality checks with their existing pruned
query, avoiding a second discovery run. The depth ceiling, sampled strata,
serial/worker degeneracy transport, and validation status remain unchanged.

This selects B's compact traversal/sign composition, A/C's stronger numeric
and coordinate-enclosure checks, and distinct ancestor-burial, hidden-cell,
and corner-exemption controls. A's extra interval queries in the root-sign
pass are unnecessary. The selected root-sign fold remains \(O(N)\); total
scratch is \(O(P+h)\), including temporary candidates later truncated. No
additional candidate budget, setting, dependency, or wire flag is introduced.

The regression is enabled with its original component/localization alternative
and standalone insufficient-depth control intact. It additionally decodes the
prepared tagged leaves and requires the actual sphere-containing finest cell
to reject discovery and remain degenerate. Focused unit controls cover both
corner exemptions, direct smooth entry, disabled quality heuristics, ordinary
sphere/box patches, the exact edge/face cases, both ancestor-burial polarities,
opaque siblings, strict-zero ambiguity, invalid/collapsed inputs, and translated
entity boxes. The lens-plus-box control explicitly passes the guard and keeps
the component-completeness limitation visible. Full worker/recovery, pruning,
transform, and measured performance matrices remain milestone-3 obligations.

The integrated source passed 34 focused native release test executions:
11 discovery/entry controls, eight reconstruction regressions, nine reliability
checks, two analytic smoothness controls, the existing forced-decision cache
control, ordinary sphere/box mesh invariants, and ordinary-box serial/worker mesh
equivalence for 1/2/4/8 partitions. The box used actual worker merge without
serial recovery. Missing sphere/box binary fixtures skipped only those tests'
external TS comparisons; no TS-oracle coverage is claimed. Single-run durations
are not benchmark medians. The coordinating agent owns the full build and
milestone-3 matrix.

\subsection{Structural work and remaining limits}

The existing optional profiler keeps counters 0--17 unchanged. Counters
18--30 record guard calls, enumeration nodes, cell queries, retained supported
occurrences, point/edge/face queries, split/indeterminate results, peak pending
entries, structural root-sign visits, strict root exclusions and all discovery
interval calls. The total interval counter checks that the root-sign walk
performs zero extra interval evaluations. Counter calls disappear in normal
release builds; instrumented durations are excluded from timing comparisons.
There is no new dependency, setting, worker wire field or success status.

The direct structural regression uses 1, 4, 16, 64 and 256 duplicate ordinary
patches. For \(n\) occurrences it visits \(n+1\) enumeration nodes, retains all
\(n\) distinct entries, performs \(8n\) point queries and at most \(12n\) edge
plus \(6n\) face queries, and visits \(n+1\) nodes in the structural sign fold.
A separately excluded subtree reaches at least 256 pending entries but ends
with one retained candidate, while only that final candidate gets entity
queries. This validates the \(O(P+h)\) peak-storage interpretation, not
\(O(K_{\mathrm{final}}+h)\). It checks linear work; it does not prove a uniform
bound on the number of cells required by the full mesher.

These observations support the agreed necessary guard on the tested domain.
They do not establish the missing general hard-CSG arrangement/component
certificate, a universal outward-rounding bound, proper-similarity validity
from a tolerance test, correctness of the pre-existing empty-cull under all

The lens remains an explicit counterexample to treating guard acceptance as

remain outside the theorem. Optimizing repeated occurrence work or tightening

uncertainty channel; this milestone supplies evidence, not authority to skip
those obligations for performance.
