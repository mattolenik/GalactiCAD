These are parametric source restrictions, not fixture IDs or coordinates.

The source checker derives a connection parameterization instead of assuming the
old unconstrained min-norm Newton parameter map is monotone. Write R for the actual
cylinder radius and r_i<R for the chosen represented incoming radius associated
with the checked original-positive query. For s in [0,1],

`rho(s) = R + (r_i - R) s`.

The actual groove edge's oriented offset-line equation determines height y(rho).
The selected extrusion side has fixed intrinsic z=v0z and
`u(rho) = sign * sqrt(rho²-v0z²)`; rotation by the actual source twist gives x/z.
Every coefficient comes from the immutable represented source. The exact-real
parameter order is explicit; strict order of every rounded representable output
is not claimed. Original raw curve ID and original parameter range are retained
in the chart, giving the affine raw-to-new interval correspondence.

## Numerical chart and connected consumers

`ConnectionChart` is inline metadata on traced data, supported only on the first
final interval [0,1]. The remainder keeps the existing traced evaluator. The new
query encloses sqrt/trig/source arithmetic with the existing interval machinery,
returns a bounded midpoint, and rejects failures; the exact stored corner position
is returned at t=0 after independent source association. The actual-query image
includes that override separately from the ideal-source image.

The stored join is exactly `chart.point(1)`. Before installation the old Newton
query at that same stored point must return it unchanged. Every chart query checks
both original carrier residuals and the existing displacement-box postcondition.
The chart has its analytical tangent. Its full image is checked inside the first
indexing segment's padded envelope and explicitly included by projection_tube.
Thus existing spatial indexing bounds remain conservative. Shared checked queries
retain their independent containment postcondition. Crossing consumers use those
queries; no floating evaluator-totality claim is made.

Storage accounting includes the larger inline traced payload; there is no new
heap-owned proof graph. Clone equality and worker fingerprint include chart
semantics, including source coefficients, endpoint override, and raw parameter
transport. A control changes only hidden chart metadata and requires both identity
checks to notice. A corrupted chart endpoint must fail the original residual gate.
Any later integration must rerun complete storage/component checks because the
inline payload size changed.

## Transactional admission and preservation

Original trimming and corner-candidate collection finish before repair admission.
A candidate source-pair attachment already represented by any original resolved
run is conservatively declined before changing its bounds or splits. This does
NOT certify that ordinary representation or transfer authority from it. It avoids
silently discarding a new source certificate through the legacy sampled dedup.
A complete remake/envelope/join preflight also runs before mutation.

Only an admitted missing attachment expands to the saved raw start. Its candidate
ID comes from the independent source-junction association, not unconditional nearest
snapping. Source-certified open-prefix intervals cannot be split at an unproved
extra candidate. If later remake unexpectedly fails, the old truncation remains
unwired. Bounded test-only events record every admission, conservative refusal,
suppressed cut, remake refusal, collapsed stub and deduplication.

The actual-source test also compiles the same binary with only the resolver
disabled. Every non-target source family's ranges, indexing geometry and corner
positions must remain bit-identical, and total curve count must remain unchanged.
The target pair test IDs are witness selection only. The unchanged full-source
regression independently requires upper coverage and all original lower source
memberships. No failed gate is removed or reinterpreted.
