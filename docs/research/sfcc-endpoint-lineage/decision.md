## Static observations and interpretation limits

Both proposals preserve the existing query sequence and short circuits in their
observation-stripping checks. B wraps status/flank bodies to inspect the returned
`Result`; the wrappers are semantically transparent even outside the cfg-gated
hooks, but the source text is not literally unchanged. Root's observed/unobserved
comparison remains necessary. New source hooks and helpers must remain test-only.

The stream's 512 KiB and 4,096-event limits are distinct from process RSS, source
compilation memory and the private constructor's 64 MiB reservation. The off/on
comparison snapshots are separate diagnostic allocations. Scope drop/take must
clear state; inactive record closures must not be materialized.

The selected automatic join is a target-lineage join, not a universal provenance
proof. In particular, a discarded duplicate without a recorded retained witness
cannot support a separate claim about why that discarded curve was redundant.
If an actual target loss depends on such unobserved data, stop with an incomplete
causal attribution rather than fill the gap by inference.

A raw indexing range extending past the source-certified height is an indexing
observation, not a continuous coverage theorem. The actual near-point classifier
records and source binding must connect it to the already accepted supporting
branch. Preserve `Err(())` as uncertainty, separate from `Ok(false)` absence.
Candidate refinement and merging must be checked before equating a trim bracket
with the final stored endpoint.
