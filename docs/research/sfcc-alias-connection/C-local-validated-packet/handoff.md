# C-local: source-qualified first-cell repair experiment

Frozen source: `/tmp/sfcc-alias-c-local`.

This is a local mechanism experiment, not a complete component transaction. The
source combines reviewed A authority/queries, B's typed Y-face point gate, and the
executed C graph-entry replay. No build, test, field evaluation or geometry run was
performed by this agent. Root must run `alias_c_` (four tests) with
`SFCC_ALIAS_C_RECEIPT` set. The new test writes `alias-C-local.json` beside that
receipt BEFORE its final assertions, so a refusal or geometric failure is evidence
rather than an absent report.

## Composition and changes

Start from `/tmp/sfcc-alias-b-typed-reviewed-fixed`, replace its `alias_a.rs`,
`alias_a_tests.rs` and `correlated_transport_a.rs` with A-authority-reviewed versions,
and retain B's `private_arc_a.rs` (same A active-query-scope API plus B's note helper).
Add C's exact graph fixture/test module. The new local changes are:

- `cell_mesh.rs`: an explicitly test-only/scoped fallback from the existing
  `transport_shared_arc` global-endpoint refusal into the new qualified helper.
- `alias_graph_c_tests.rs`: existing two baseline controls, the qualified sharing
  helper and scoped replay, one positive actual-cell test and one adversarial test.
- `alias-graph-replay.json`: additionally stores the actual private FaceRecord
  from the same previously captured component receipt.

The hook is compiled only with test+serde and is inactive outside the replay's
RAII scope. A non-test library or ordinary private component run therefore does
not silently acquire this local face-preparation policy. This is deliberate:
neighbor consumers, all six paired faces and the activation frontier remain open.
The scoped mechanism is not a new export setting.

## Qualified local sharing

The helper retains exact endpoint-ID agreement after the typed preparation. It
recognizes actual native/inner-round source roles through source-descriptor APIs,
finds the unique supported cylinder occurrence by trying A's binding, and rejects
ambiguous source certificates. It supports only the consumed prefixes beginning
at both original t_min endpoints; remote ranges and different endpoints remain
unsupported. No curve is removed from the feature index or corner incidence.

A fresh certificate is bound to the private feature clone. All actual curve queries
require the active GeneratedQueries scope and remain recorded against its existing
2,048 reservation. The helper cannot run without that scope. It preserves the
existing64-request/iteration and16,384-total policy supplied by A/the outer ledger.

For every retained canonical node, both original queries are checked directly
against that same stored position. Target endpoint parameters remain EXACTLY the
original target parameters, with direct own-to-own agreement too. Interior target
parameters use A's checked inverse. Both raw parameter sequences and both actual
query radius sequences must be strictly ordered, as must the retained canonical
node radii. No chain of tolerances grants retained-point agreement.

The helper also retains the old target quarter/midpoint chord checks and the checks
of every original target node. Their actual queries/source associations are checked
against the original physical polyline at the original half-chord allowance. Both
curve interval identities are retained on the one reused geometric edge chain.

The new code does not reorder vertex angles, flip triangles, loosen source domains,
change tolerances or disable the repeated-vertex guard.

## Required local outcome and negative controls

The actual graph must return success without unresolved filling. The emitted mesh
must have no duplicate faces, exactly the prepared directed boundary, opposite
interior edge uses, positive existing SDF-reference orientation in both precisions,
and no contact conflict under the existing GrowingIndex checker in either precision.
Both curve identities must remain on every shared physical feature edge.

These are measured local requirements, not promised results. A test failure must
be diagnosed from the saved report without weakening any assertion.

The adversarial test rejects distinct endpoint IDs, a displaced canonical stored
point, a changed native source, and missing generated-query scope. It restores the
point after mutation and checks scope cleanup after panic. Existing baseline tests
still reproduce the original refusal with the hook inactive.

## Explicit limits

Even local success would not establish whole-face-consumer closure, the all-six-face
transaction, a valid transition where native46 and composite66 cease to coincide,
complete component reconstruction or two-dimensional patch ownership. The floating
triangle orientation/contact checks remain checks of this local candidate, not a
continuous Hausdorff or global topology theorem. The implementation does not claim
that the old Newton query map is continuous or universally total.
