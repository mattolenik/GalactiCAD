## Construction and mathematical authority

The transaction searches existing native/alias pairs that share their lower corner and identifies their actual source roles with the existing HelixBranch source binding. The existing source junction and the new bounded lower certificate supply the mathematical authority. Dense curve/corner IDs and geometric proximity do not select an attachment on their own.

The actual lifted traced carrier pair must match the certificate's retained source root and embedded descriptors. A candidate must be open, have no current end corner, start at parameter zero and have a finite integer last span within128 spans. Two actual own queries propose the old last join and old endpoint. Their heights propose source levels through the source certificate's affine height relation; both must then pass the same bounded three-dimensional ideal-image association. This is a numerical proposal check, not authority derived from height alone.

A fresh full-source interval is bound from the actual join level through a=0, with depth at most0.25. The certificate covers the whole replacement and has a nonzero height derivative and source-coordinate Jacobian. It does not prove the old Newton map is continuous. The replacement keeps the raw outer parameter range, uses the last unit span, retains the exact existing checked join at its start and the exact existing source corner at its end, and supplies the bounded canonical source image between them.

Installation also requires the old stored indexing knot to equal the checked join bit-for-bit. Otherwise changing that knot could alter the preceding untouched interpolation span. The original projection must return that exact join unchanged, both endpoint carrier residuals remain within the existing curve epsilon, and the complete ideal image fits the existing expanded indexing envelope. Every future actual query still checks its own carrier residuals and independent displacement box. The broad installation envelope does not establish universal floating-query success.

All replacements and cloned corner records are prepared before publication. The transaction preserves existing incident ends and strata, adds the required lifted end/source pair, and refuses ambiguity or repeated use of one curve for multiple corners.
