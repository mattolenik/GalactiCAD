**The lower lifted connection is implemented in the isolated experimental source.**
It preserves the existing join and corner, adds the missing branch and source
memberships, and carries the bounded source authority through the five identified
endpoint/query/sampling consumers. The selected combined implementation passes

all 1,167 generated events finish validation using 5,568 charges under the unchanged

## Lower connection implementation

The constructor uses the proved lower chamfer interval from the previous round.
It identifies the actual native/alias source roles and existing source junction,
then seeks an open lifted trace whose embedded sources match. Actual checked
queries propose the last join and old endpoint. Height proposes their source
parameters; fresh interval certificates and three-dimensional association bounds
must confirm both proposals. Height alone grants no connection authority.

For this execution, chart 75's last raw span [12,13] is replaced with the ordered
canonical source interval ending at corner 13. Its outer parameter range and start
corner remain unchanged. The stored indexing knot must equal the old checked join
bit-for-bit, and the existing projection must leave that join unchanged. These
requirements keep the preceding span's interpolation seed intact. The final point
is exactly the existing source corner.

The source parameter proposed from height need not be bit-identical to the previous
proof experiment's parameter proposed from `native.f(join)`. The runtime independently
binds and checks its own interval under the same allowance; it does not reuse an
unchecked numerical coefficient.

The boxed lower-chart metadata supplies point evaluation, ideal image bounds,
tangent evaluation, provenance and source identity. Point queries retain the
original carrier-residual and per-query displacement checks. A failed certified
query returns failure; the unchecked convenience path returns NaNs rather than
falling back to ordinary interpolation. Index bounds enclose the source image and
the exact stored endpoints. This does not prove every floating query succeeds.

All proposed curve and corner changes are prepared before commit. The transaction
rejects ambiguous candidates, reuse of one curve for multiple corners, stale
ranges, invalid/duplicate/oversized incident lists, foreign source roots and
incompatible embedded carriers. Its late-refusal control preserves the original
geometry, fingerprint and retained source identity.

The event gate recognizes the supported source event independently of optional
chart metadata. It requires all four physical source-ray roles and preserves the
existing incident ends, including aliases. Removing the new chart metadata or an
older required ray cannot restore acceptance. This is a source-role completeness
check; it does not provide new continuity or patch certificates for every old arc.

Qualified lower membership uses the existing shared membership entry point, so
the five previously identified consumers use the same narrow authority. Ordinary
discovery ownership bands and numerical tolerances remain unchanged. The event
gate itself adds no unreserved curve queries to private admission; the original
charged endpoint loop still checks actual endpoint queries.

Fingerprinting includes the new geometric/provenance state. Exhaustive clone and
storage audits include the box, incident vector, retained root handle, embedded
strata and certificate fields. They do not treat a reference as a copied proof.

## Query improvement under the same acceptance contract

C adds at most two height-interpolated proposals inside the existing 64-iteration
inverse loop. Inputs must be finite, target height must lie strictly inside the
checked bracket, and the rounded parameter must be strictly interior. Invalid
proposal arithmetic uses the existing midpoint. Subsequent iterations use bounded
bisection. Bracket heights come only from checked curve queries.

Every proposed point goes through the existing source, branch, container and
outward three-dimensional distance checks. A failed actual query still refuses;
it is not hidden by trying another proposal. Cancellation, cache identity,
pairwise distance, sequence order, request/total caps and memory checks remain.
No reservation is refunded and no correspondence cache is introduced.

Original query inputs and points match bit-for-bit. There are 246 changed mapped
parameters; each result independently passes the unchanged allowance. The largest

not a universal performance guarantee or a claim of identical mapped geometry.
Two unsuccessful proposals can spend budget differently from midpoint-only search.

## Exact newly reached failure

The final diagnostic retains per-cell triangle ranges and the exact point/triangle
arrays: **1,064 points and 1,700 triangles**. All 199 ranges are contiguous and cover
the array. Compact geometry occupies 88,489 bytes, below its 512-KiB diagnostic cap.
The overall diagnostic harness retains its 64-MiB cap. Diagnostic JSON is separate
from the source-clone reservation.

The guard first refuses triangle **11**, vertex IDs **[636,455,633]**, from cell
**[7,25,58,86]**. This is the first cell's range [0,30). Its edge 455→633 is identified
with curve 66; the other two edges have no recorded curve membership. Patch ownership
is absent. The saved fixture preserves exact coordinate and reference bits.

| Existing predicate measurement | Working f64 | Exported f32 coordinates |
| --- | ---: | ---: |
| Twice area | 5.21558045319592e-7 | 5.218858315133539e-7 |
| Triangle normal dot stored reference | -5.215580451572934e-7 | -5.218854907818899e-7 |
| Normal/reference cosine | -0.9999999996888198 | -0.999999347114937 |
| Exact represented-coordinate area | Nonzero | Nonzero |
| Exact represented-coordinate dot sign | Negative | Negative |

Coordinates, areas and reference are finite. Independent rational arithmetic on
the captured binary values confirms the nonzero area and negative dot product in
both precisions. Thus the rejection is **opposition to the current gradient reference**,
not f32 collapse or uncertainty in a nearly zero dot product.

The reference is the already computed SDF gradient at the working triangle's
centroid, reused by the unchanged guard for both precisions. Capturing it adds no
field evaluations. It is not an independently certified source-patch normal.
Missing patch ownership therefore matters when diagnosing the cause. No claim is
made that the lower attachment or inverse proposal introduced this triangle defect;
this validation stage was previously unreachable. All later triangle orientations
remain unchecked in the runtime pass.

The observational capture reproduces every prior receipt field after excluding
only its new diagnostic fields and process-local addresses. Its synthetic controls
separately exercise f32 collapse, f64 collapse and reversal against the reference.
